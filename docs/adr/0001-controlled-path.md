# ADR 0001 可控教学通信路径

状态：Proposed，课程设计确认待实际记录；下述方案已由用户授权实施，不等于教师逐项批准。2026-10-22整理现状，关联SEC-01、IPC-01、SEC-03、ISO-01、REL-01。

## 背景

目标是完成可重复、可恢复的资源管理器IPC测试。普通用户态监控进程不能仅凭存在就透明拦截其他客户端的所有MsgSend；全系统改造和真实服务风险超出首版范围。

## 备选与决定

| 方案 | 评价 |
| --- | --- |
| 全系统透明拦截 | 实现/授权边界不满足，首版不采用 |
| 独立强制代理 | 需证明设备访问受约束及身份传递；作为后续候选，不声称已实现 |
| 自建资源管理器及客户端应用网关 | 已采用的工程路径，通信与恢复可控；接受可被直接设备访问者绕过 |
| 只有旁路监控 | 能观察但不能证明主动阻断，不能单独满足SEC-03 |

选择单一自建/dev/ipcsec-lab、合法devctl、客户端字段/频率策略及服务端边界校验。主机模拟验证流程与策略，原生C执行真实IPC，证据分开；Python逐请求QnxTransport不静默回退。

## 后果与验证

收益为输入、对照、接收审计和恢复边界明确；代价为有限协议、非可信会话和非系统强制。验证见../acceptance-matrix.md的IPC-01、SEC-03及ISO-01；历史原生说明见../../review/native-defense-milestone.md。超时、受控退出和完整隔离分别解释。

## 回退及重议条件

原生门失败时停止相关实测，保留模拟和失败证据，不扩展目标。若要求不可绕过防御，需另做服务端策略或受设备权限约束的代理设计并取得相应范围确认，不能改名冒充实现。
