# ADR 0003 只计获准转发请求的会话窗口

状态：用户业务语义已决定，主机修复回归有记录；伙伴复核pending，非教师最终验收。决定依据为../../review/DEC-SEC04-rate-accounting.md；本ADR于2026-10-22整理，不追认新事件。关联SEC-04、OBS-01。

## 背景与备选

INT-F-01发现Python先追加再限流，而C在满窗口时不追加，导致同一21例时序最后一项不同。方案A只计放行，方案B计全部结构合法到达；二者都可成为产品语义，但不能两后端混用。

## 决定

采用用户选择A：窗口(now−1000ms,now]内最多10次有效ALLOW，拒绝不占槽、不延长窗口；计数发生于IPC调用前，不以成功应答计数。恢复授权不清空历史。默认10不变，CH-01的5仍候选模拟。

## 后果、验证与回退

避免拒绝请求持续延长封锁；不能以此防御非法请求自身的处理资源消耗。会话标签非认证，可绕过客户端网关的程序不受此策略强制约束。

Python修复、21例反例与5/10边界回归见../../review/findings/INT-F-01-rate-accounting.md；原生C本次未改。该反例复核在主机进行，不声称QNX新实测。若改为方案B，需新Change、足够计数容量、两后端新对照及回滚证据，不覆盖旧记录。
