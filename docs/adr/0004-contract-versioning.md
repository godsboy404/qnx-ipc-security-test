# ADR 0004 当前契约、历史证据与模型登记分离

状态：本轮文档整理采用的工程方案，待项目成员评审及冻结；不等于教师批准。2026-10-22，关联OBS-01、ISO-01、REL-01。

## 背景与备选

旧Spec混合现行规则和阶段时间线，且登记预检绑定文件哈希。直接重写并静默换哈希会隐藏评价上下文变化；继续追加更新则增加歧义；为旧契约添加多版本执行支持会扩大本轮功能范围。

## 决定

保留逐字节旧Spec/登记快照，建立ipcsec-spec-draft-0.3项目草案，显式更新当前登记的ID和哈希；不改程序、release条目或历史模型档案。当前规则放Spec，状态放continuity，历史事实留原档案，需求/实现/检查/证据映射放验收矩阵。迁移细节及旧绑定验证见../contracts/README.md。

## 后果与验证

程序仍只支持一个当前契约，不声称并行支持旧版本。旧packet与当前登记不相等是预期隔离；新packet不继承旧模型资格。v2真实材料门未通过的事实不变。快照哈希、历史文件保护清单、三criterion本地预检和主机回归共同验证迁移。

## 回退与重议

如本轮变更未被接受，通过评审后的精确文件差异回退当前文档及登记，不reset学生工作树、不改历史证据；旧快照可供比较，禁止把旧模型结果重新贴到新版本。多版本预检若成为需求，另立功能变更。
