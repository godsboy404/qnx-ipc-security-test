## 已实现字段的解释

ipcsec/metrics.py的false_positive_rate = 结构合法用例中decision不为ALLOW的数量 / 结构合法总数。保留旧字段及原始summary，此字段更准确表示结构合法输入非放行比例，包含正确限流，不能称为策略错误误拒率。invalid_prevention_rate与invalid_allow_rate按结构非法oracle分组；语法非法不等于恶意，语法合法不等于安全。

## 候选分析口径（尚未改计算实现）

| 指标 | 分子 / 分母 |
| --- | --- |
| 非法输入阻断率 | 不转发的结构非法用例 / 结构非法用例 |
| 非法放行率 | 实际转发的结构非法用例 / 结构非法用例 |
| 策略错误拒绝率 | 独立情境oracle应放行但被拒的用例 / oracle应放行用例 |
| 正确限流拒绝 | oracle认定超窗口且实际限流的数量，单列计数及对应样本总数 |
| 正确授权拒绝 | oracle认定撤权/范围不足且实际拒绝的数量，单列计数及对应样本总数 |
| 防御开销 | 同负载时间/资源增量及绝对值，模拟逻辑时间不替代实测 |
| 隔离成功率 | 完整观测下成功隔离的确认故障 / 完整观测的确认故障；当前不可计算 |

新口径需独立冻结oracle、时序和分类，并通过后续实现/回归才可输出正式指标；本轮只澄清定义，不宣称已支持。零分母返回null或N/A并说明；确认故障、完整观测、成功、失败与未知分列，不能丢弃未知。Timeout保留在总体耗时，成功子集另列。穿过网关不等于利用成功，受控SIGTERM不是漏洞崩溃。重复结果报告分布及样本数，正式性能阈值/Trial/人工成本仍待确认。
