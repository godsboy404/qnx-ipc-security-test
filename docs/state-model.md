# 状态与决策模型

用例状态：CREATED -> REGISTERED -> VALIDATED -> SENT -> OBSERVED -> ARCHIVED。
拒绝路径：REGISTERED/VALIDATED -> REJECTED -> ARCHIVED。撤权和预算耗尽不得继续SENT。
策略决定：ALLOW / BLOCK / RATE_LIMIT；告警作为独立事件。
执行结果：NOT_SENT / REPLY / ERROR_REPLY / TIMEOUT / CRASH / UNKNOWN。
主机模拟仅有REPLY、ERROR_REPLY、NOT_SENT、SIMULATED_FAULT；无真实CRASH或TIMEOUT模拟观测。
隔离判定：完整且确认故障 -> PASS/FAIL；没有故障 -> NOT_APPLICABLE；观测缺失 -> INCONCLUSIVE。
禁止从TIMEOUT直接转CRASH或隔离PASS。
