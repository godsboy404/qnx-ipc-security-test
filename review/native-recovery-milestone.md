# 自建服务受控退出与恢复验证

日期：2026-10-17。关联REL-01、ISO-01、OBS-01。运行ID：20261017T124025Z-59242bdb。
范围：用户自建QNX 8.0 x86_64 VM中的/dev/ipcsec-lab，仅控制本轮启动的服务进程。教师Gate及伙伴签署pending。

## 实测结果

| 项目 | 实际观测 |
| --- | --- |
| 停止前合法请求 | 10次正确应答，接收审计10条 |
| 服务受控退出 | 监督进程主动发送SIGTERM；waitpid确认信号15，原目标PID 12247067 |
| 停机窗口 | 设备路径消失，独立客户端open返回ENOENT=2，没有IPC发送 |
| 重启及应答 | 新目标PID 12259355；10次正确应答，接收审计10条 |
| 独立只读OS探针 | 总44条成功观测；严格位于正常/停机/重启后三阶段的分别11/11/15条，其他为阶段边界观测 |
| 清理 | 本轮6个子进程均回收，设备路径消失 |

探针使用独立PID 12247066执行uname与只读stat(/proc)，持续覆盖受控退出与恢复。监督、两代服务、三个阶段客户端与探针共7个不同PID。前后每次请求的字节、时间和目标PID与独立服务端审计逐条核对。

停止请求至首个恢复应答约297.21ms；重启请求至首个恢复应答约36.91ms；确认退出至重启请求之间约237.57ms，包含主动保留的停机观察窗口。这是单次实验观测，不是P95、性能阈值达标或纯进程启动耗时。

证据位于evidence/native-recovery-runs/20261017T124025Z-59242bdb/，包括八阶段事件、监督采样、探针原始结果、三个客户端结果、两代服务接收审计及清理记录；manifest保存源码、二进制及证据哈希。宿主45秒截止未触发，远端返回0。
严格编译通过，28项主机回归通过，其中6项恢复证据测试使用明确标注的合成fixture，不冒充QNX实测。

## 结论与边界

受控退出、不可用窗口、新PID恢复与应答的验收结果为PASS。该信号由监督进程主动发送，不能称为发现漏洞、非预期crash或Fuzzer触发故障。独立探针仅覆盖本轮uname和/proc只读操作，不涵盖其他系统服务或全部系统健康。完整隔离结论保持INCONCLUSIVE，不计算隔离成功率。
本轮检查恢复快照IPC-Ready-20261015仍存在；未执行快照回滚，服务依靠进程重启恢复。每次IPC 2秒、监督15秒、宿主45秒截止；故意阻塞触发超时尚未实测。
